BLOQUE 3 // SEMÁNTICA

POLISEMIA Y CAMPO SEMÁNTICO

Una palabra, muchos significados + palabras que van juntas

1. POLISEMIA - Una palabra, varios significados

Misma palabra, significados relacionados entre sí. Depende del contexto.

Ejemplos que SIEMPRE salen en EXANI

  • BANCO: Banco de sentarse / Banco de dinero / Banco de peces -> todo es "conjunto donde se guarda/apoya"
  • GATO: Animal / Herramienta para levantar coche / Persona de ojos
  • CAPITAL: Ciudad capital / Dinero capital / Mayúscula capital
  • PLANTA: Planta vegetal / Planta del pie / Planta industrial / Planta de luz
  • Sierra: Herramienta / Cadena montañosa
  • Hoja: Hoja de árbol / Hoja de papel / Hoja de cuchillo
DIFERENCIA CLAVE CON HOMÓNIMOS:
Polisemia = significados PARECIDOS con origen común (banco asiento y banco dinero vienen de "banca" italiana)
Homonimia = significados NADA que ver, coincidencia (ola mar y hola saludo)

EXANI no te pide distinguir, solo reconocer que es polisémica

2. CAMPO SEMÁNTICO - Familia de palabras por tema

Conjunto de palabras que hablan del mismo tema.

Ejemplos fáciles

  • Campo semántico de FÚTBOL: balón, portería, gol, árbitro, cancha
  • Campo semántico de ESCUELA: maestro, alumno, pizarrón, tarea, examen
  • Campo semántico de MÉDICO: estetoscopio, paciente, bisturí, hospital
  • Campo semántico de COLORES: rojo, azul, verde, amarillo

Truco EXANI

  • Te dan 4 palabras y una no pertenece:
    rosa, clavel, perro, tulipán -> perro no es campo semántico de flores
  • O te piden incluir: "¿Qué palabra pertenece al campo semántico de cocina?"

3. FAMILIA LÉXICA vs CAMPO SEMÁNTICO (te confunden)

  • Familia léxica: Misma raíz -> pan, panadero, panadería, panecito
  • Campo semántico: Mismo tema pero diferente raíz -> pan, mantequilla, leche, jamón (desayuno)

Otros conceptos rápidos que vienen juntos

  • Denotación: Significado literal de diccionario (perro = animal canino)
  • Connotación: Significado figurado/emocional (perro = insulto, fiel)
  • Ej: "Eres un sol" denotación = estrella, connotación = eres lindo/brillas
